# Manda Express Boutique

# PROMPT MESTRE — MANDA EXPRESS

## Criação de uma Landing Page Profissional de Vendas



### 1. IDENTIDADE DO PROJETO



Cria uma landing page moderna, elegante, minimalista e totalmente responsiva para uma loja chamada **MANDA EXPRESS**.



A Manda Express é uma loja que comercializa produtos selecionados em três categorias:



- Relógios

- Tênis

- Roupas



A loja trabalha com um catálogo pequeno e exclusivo. Não deve parecer um marketplace, supermercado ou uma loja com milhares de produtos.



O objetivo principal do website é apresentar os produtos de forma atraente e converter visitantes em potenciais clientes através de reservas automáticas no WhatsApp.



### 2. IDENTIDADE VISUAL



Utiliza o conceito **CLEAN STORE**.



A identidade visual deverá transmitir:

- Elegância.

- Simplicidade.

- Confiança.

- Modernidade.

- Exclusividade.



**Paleta de cores:**

- Branco: `#FFFFFF`

- Bege claro: `#F5F2EC`

- Cinza suave: `#EAEAEA`

- Preto suave: `#202020`

- Cinza para textos secundários: `#777777`



**Tipografia:**

Utiliza fontes modernas e elegantes, como Inter, Poppins ou Montserrat.



Evita excesso de cores, sombras fortes, gradientes exagerados e elementos desnecessários.



A experiência visual deve lembrar uma boutique de moda moderna e sofisticada.



### 3. ESTRUTURA DO WEBSITE



Cria uma landing page de uma única página, com navegação suave entre as secções.



**SECÇÃO 1 — HEADER**



Criar um cabeçalho elegante com:



- Logótipo tipográfico MANDA EXPRESS.

- Menu: Início, Produtos, Como Reservar e Contactos.

- Botão destacado: Reservar agora.

- Menu adaptável para dispositivos móveis.



O cabeçalho deve ser limpo e organizado.



**SECÇÃO 2 — HERO / APRESENTAÇÃO**



Criar uma primeira secção visualmente impactante.



Título principal:



"O teu estilo começa aqui."



Subtítulo:



"Relógios, tênis e roupas selecionados para quem valoriza estilo, qualidade e simplicidade."



Adicionar dois botões:



1. Explorar produtos.

2. Reservar pelo WhatsApp.



Utilizar uma fotografia realista e profissional de composição de moda, com relógio, tênis e roupa.



A imagem deve ter boa qualidade, iluminação profissional e uma composição elegante.



**SECÇÃO 3 — CATEGORIAS**



Apresentar as três categorias principais em cartões visuais:



1. Relógios.

2. Tênis.

3. Roupas.



Cada cartão deve conter uma fotografia realista, nome da categoria e botão "Ver produtos".



As imagens devem ser visualmente diferentes e representar corretamente cada categoria.



**SECÇÃO 4 — PRODUTOS EM DESTAQUE**



Esta é uma das secções mais importantes.



Criar um catálogo compacto, moderno e organizado.



Quantidade máxima inicial:



- 2 relógios.

- 3 tênis.

- 3 roupas.



Cada produto deve possuir:



- Fotografia real de alta qualidade.

- Nome do produto.

- Descrição curta.

- Categoria.

- Botão "Reservar agora".



IMPORTANTE:



Não apresentar preços em nenhum produto.



Não adicionar carrinho de compras.



Não criar checkout ou pagamento online.



As fotografias devem ser realistas, com aparência de fotografia profissional de produto, nunca desenhos ou ilustrações.



Utilizar fotografias dos artigos reais fornecidas pela loja sempre que disponíveis. Fotografias demonstrativas devem ser facilmente substituíveis e não devem ser apresentadas como artigos reais em stock.



O catálogo deve ser fácil de atualizar, adicionar ou remover produtos.



**SECÇÃO 5 — COMO RESERVAR**



Criar uma secção com três passos simples:



PASSO 1 — Escolhe o produto.



O cliente navega pelo catálogo e encontra o artigo que deseja.



PASSO 2 — Clica em reservar.



O botão abre automaticamente uma conversa no WhatsApp.



PASSO 3 — Confirma a reserva.



O cliente envia a mensagem e combina os detalhes diretamente com a loja.



Utilizar ícones minimalistas e uma apresentação visual elegante.



**SECÇÃO 6 — CHAMADA PARA AÇÃO**



Criar uma secção de destaque com a seguinte mensagem:



"Encontraste o teu próximo estilo?"



Texto complementar:



"Escolhe o teu produto favorito e faz a tua reserva diretamente connosco."



Botão principal:



"RESERVAR PELO WHATSAPP"



**SECÇÃO 7 — RODAPÉ**



Adicionar:



- Logótipo MANDA EXPRESS.

- Pequena descrição da loja.

- Links de navegação.

- Categorias disponíveis.

- Contacto WhatsApp.

- Direitos reservados.



Texto de rodapé:



"© 2026 Manda Express. Todos os direitos reservados."



### 4. SISTEMA DE RESERVA AUTOMÁTICA PELO WHATSAPP



O WhatsApp é o principal canal de conversão do website.



Número oficial:



**+244 921 810 795**



Utilizar o link:



https://wa.me/244921810795



Cada produto deverá ter o seu próprio botão de reserva.



Quando um cliente clicar no botão de um produto, abrir o WhatsApp com uma mensagem automaticamente preenchida.



Exemplo de mensagem:



"Olá, Manda Express! Gostaria de reservar o seguinte produto:



Produto: [Nome do Produto]



Categoria: [Categoria]



Gostaria de receber mais informações sobre a disponibilidade e a reserva. Obrigado!"



A mensagem deverá ser construída dinamicamente de acordo com o produto selecionado.



Todos os botões de reserva devem funcionar corretamente.



### 5. FUNCIONALIDADES



Implementar:



- Navegação suave entre secções.

- Menu responsivo.

- Botões funcionais.

- Integração com WhatsApp.

- Catálogo de produtos compacto.

- Filtragem por categoria.

- Animações suaves ao aparecerem os elementos.

- Efeitos discretos ao passar o cursor nos cartões.

- Botão flutuante de WhatsApp.

- Imagens otimizadas para carregamento rápido.

- Layout adaptado a computadores, tablets e telemóveis.



### 6. EXPERIÊNCIA DO UTILIZADOR



A experiência deve ser simples.



O visitante precisa de compreender rapidamente:



1. O que é a Manda Express.

2. Que produtos vende.

3. Quais produtos estão disponíveis no catálogo.

4. Como realizar uma reserva.



Não sobrecarregar o visitante com informações desnecessárias.



Dar prioridade às fotografias dos produtos e aos botões de reserva.



### 7. REQUISITOS TÉCNICOS



Desenvolver com tecnologias modernas.



Preferencialmente:

- React.

- Tailwind CSS.

- Componentes reutilizáveis.

- Código organizado.

- Design responsivo.

- Boas práticas de SEO.

- Boa acessibilidade.

- Carregamento rápido.



Criar uma estrutura de dados centralizada para facilitar a atualização dos produtos, nomes, descrições e imagens.



O código deve ser limpo, organizado e funcional.



Não utilizar botões decorativos sem funcionalidade.



### 8. INSTRUÇÕES FINAIS



O resultado deve parecer um website de uma marca comercial profissional, e não um template genérico.



O design deve ser minimalista, sofisticado e visualmente atraente.



Não inventar preços, avaliações, depoimentos, políticas de entrega ou informações comerciais que não tenham sido fornecidas.



Não adicionar categorias que não foram solicitadas.



Não transformar a landing page numa loja online complexa.



O foco principal é apresentar poucos produtos de forma elegante e converter visitantes em reservas através do WhatsApp.



**RESULTADO ESPERADO:**



Uma landing page profissional, responsiva e visualmente impressionante para a MANDA EXPRESS, com fotografias de qualidade, catálogo compacto e sistema de reserva direta pelo WhatsApp.



A prioridade máxima é a apresentação visual dos produtos e a facilidade de reservar.
